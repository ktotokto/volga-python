# UI Автотесты

Проект автоматизированного тестирования веб-интерфейса сайта `practice-automation.com`.

## Технологический стек

- **Язык:** Python 3.12+
- **Фреймворк:** Pytest
- **Библиотека:** Selenium WebDriver
- **Отчетность:** Allure Report
- **Паттерн:** Page Object Model (POM)

## Структура проекта

```
volga-python/
├── conftest.py                 # Фикстуры Pytest, инициализация браузера, хук для скриншотов

│   └── ads_page.py             # Локаторы и методы страницы Рекламных окон
├── tests/                      # Тестовые сценарии
│   ├── __init__.py
│   ├── test_calendar.py        # Тесты для календаря
│   ├── test_modal.py           # Тесты для модальных окон
│   └── test_ads.py             # Тесты для рекламных окон
├── utils/                      # Вспомогательные утилиты
│   ├── __init__.py
│   └── automation_tools.py     # Скрипт для парсинга данных (спец. требование ТЗ)

```
## Описание тестовых сценариев
### 1. Страница "Календарь" (/calendars/)
#### Позитивные сценарии:
-  Ввод корректной даты в формате YYYY-MM-DD.
-  Ввод даты в прошлом.
-  Ввод даты в будущем.
-  Ввод даты високосного года .
-  Ввод даты на границе года.

#### Негативные сценарии:
-  Отправка пустой формы календаря.
-  Ввод некорректного текстового формата .
-  Ввод несуществующей даты.

### 2. Страница "Модальные окна" (/modals/)
#### Позитивные сценарии:
-  Открытие простой модалки (Simple Modal).
-  Проверка заголовка и содержимого простой модалки.
-  Закрытие простой модалки по кнопке.
-  Открытие модального окна с формой (Form Modal).
-  Проверка заголовка модалки с формой.
-  Успешное заполнение и отправка формы в модальном окне.
-  Закрытие модалки с формой по кнопке крестика.
-  Закрытие модалки с формой клавишей Escape.

#### Негативные сценарии:
-  Отправка пустой формы в модальном окне (проверка появления "Please fill out the form correctly").
-  Отправка формы с пустым полем Name (проверка конкретной ошибки для Name).
-  Ввод некорректного email в форму модалки.

### 3. Страница "Рекламные окна" (/ads/)
-  Проверка автоматического появления рекламной модалки.
-  Проверка содержимого рекламы.
-  Закрытие рекламной модалки и проверка её исчезновения.

## Запуск
### 1. Установка зависимостей
```
pip install -r requirements.txt
```
### 2. Запуск тестов
```
# Все тесты
pytest

# Только тесты календаря
pytest tests/test_calendar.py

# Только тесты модальных окон
pytest tests/test_modal.py

# Только тесты рекламных окон
pytest tests/test_ads.py
```
### Запуск с отчётом Allure
```
# Генерация данных отчёта
pytest --alluredir=allure-results

# Открытие отчёта в браузере
allure serve allure-results
```

## Отчёт Allure
Отчёт Allure настроен и содержит:

-  Overview: Общая статистика по тестам (пройденные/упавшие).
-  Suites: Группировка тестов по страницам (Календарь, Модальные окна, Рекламные окна).
-  Steps: Детальные шаги каждого теста, реализованные через декоратор @allure.step().
-  Attachments: При падении теста (AssertionError, TimeoutException и т.д.) автоматически прикрепляются:
    -  Скриншот состояния браузера на момент ошибки.
    -  HTML-код страницы для отладки.
